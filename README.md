# DAYOUT

**What are we doing?**

DayOut is a mobile-first, constraint-aware day planner. Tell it where you are, when you're free, what you're into, and what matters, and it finds things you can actually do right now.

Core rule: **never send someone to a closed business.** Only businesses confirmed open for the relevant part of your visit are ever recommended.

Part of the same family as PowNow (ski), TREAD (outdoor routes), and RIDEOUT (riding destinations).
